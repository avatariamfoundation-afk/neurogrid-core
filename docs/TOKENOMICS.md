# TOKENOMICS.md

## NeuroGrid Tokenomics Framework  
**Hackathon Implementation vs Real-World Economic Model**

**Status:** ACTIVE  
**Applies To:** NeuroGrid (BNB Hackathon Submission & Post-Hackathon Launch)  
**Audience:** Judges, auditors, contributors, future partners, regulators

---

## 1. Executive Positioning

NeuroGrid operates under a **dual-token narrative** that is intentional, transparent, and industry-standard for early-stage protocol development:

- **MedToken** → Hackathon-scoped, non-economic, functional placeholder  
- **ABSToken** → Real-world utility, governance, and value-accrual token post-hackathon  

This separation ensures:
- Hackathon compliance and simplicity
- Zero premature economic promises
- Clean transition to a production-grade token model
- Regulatory and reputational safety

This is **not indecision** — it is disciplined protocol design.

---

## 2. MedToken (Hackathon Token)

### 2.1 Purpose

**MedToken** exists exclusively to:
- Demonstrate incentive flows
- Validate smart-contract logic
- Enable testnet reward distribution
- Showcase DeSci and compute incentives

It is a **functional artifact**, not an economic instrument.

### 2.2 Characteristics

| Attribute | Description |
|----|----|
| Network | BNB Testnet |
| Scope | Hackathon only |
| Transferability | Limited / testnet |
| Supply | Arbitrary / capped for demo |
| Economic Value | None |
| Governance Power | None |
| Post-Hackathon Fate | Deprecated |

### 2.3 Explicit Non-Claims

MedToken:
- ❌ Is not an investment
- ❌ Has no monetary value
- ❌ Is not intended for listing
- ❌ Will not migrate to mainnet
- ❌ Will not convert to ABSToken

This clarity protects both the project and participants.

---

## 3. ABSToken (Post-Hackathon Real-World Token)

### 3.1 Purpose

**ABSToken** (Aethera BioSync Token) is the **future economic backbone** of NeuroGrid.

It is designed to support:
- Decentralized compute incentives
- Scientific contribution rewards
- Validator and node staking
- Governance participation
- Long-term ecosystem sustainability

ABSToken development is **intentionally deferred** until:
- Hackathon evaluation concludes
- Awarded funds are secured
- Professional audits are engaged
- Legal and regulatory frameworks are finalized

---

## 4. ABSToken Utility Domains

ABSToken will be used for:

### 4.1 Compute Economy
- Payment for off-chain AI compute
- Rewards for compute nodes
- Slashing for misbehavior

### 4.2 Scientific Incentives (DeSci)
- Rewarding verified research contributions
- Funding community-approved studies
- Supporting reproducibility incentives

### 4.3 Governance
- DAO voting
- Proposal execution
- Parameter tuning (fees, limits, thresholds)

### 4.4 Network Security
- Validator staking
- Fault-based slashing
- Trust score reinforcement

---

## 5. Funding & Development Commitment

### 5.1 Hackathon Award Allocation (Planned)

If awarded, hackathon funds will be **explicitly allocated** toward:

- ABSToken smart-contract design
- Professional security audits
- Tokenomics simulations
- Legal & compliance advisory
- Initial infrastructure deployment
- Exchange listing preparation (non-speculative)

This ensures funds are used for **infrastructure**, not hype.

---

## 6. Regulatory & Ethical Position

NeuroGrid deliberately avoids:
- Premature token issuance
- Speculative token narratives
- Implicit investment language

ABSToken will be launched only after:
- Clear utility is live
- The system is battle-tested
- Governance structures are active
- Compliance pathways are evaluated

This approach aligns with:
- Responsible DeSci principles
- Healthcare-adjacent ethical standards
- Long-term protocol credibility

---

## 7. Transition Strategy (MedToken → ABSToken)

There is **no automatic migration**.

Instead:
1. MedToken is retired post-hackathon
2. ABSToken launches as a clean, audited system
3. New contracts and registries are deployed
4. Governance ratifies economic parameters
5. Ecosystem transitions by choice, not force

This avoids technical debt and legal ambiguity.

---

- MedToken exists only to prove the system works
- ABSToken is the real future token
- No fake promises, no rushed economics
- Hackathon funds accelerate real deployment
- This mirrors best practices in serious Web3 protocols

NeuroGrid chooses **credibility over shortcuts**.

ABSToken validates the future.
